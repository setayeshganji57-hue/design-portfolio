This page exists only to show how a long-form text will read once real essays arrive. Every element below — headings, quotations, lists and notes — is styled by the template, so the final texts can be pasted in as Markdown without touching any layout code.

## A section heading

Body text is set in a comfortable column of roughly sixty-five characters per line, with generous leading. Paragraphs are separated by space rather than indents, which keeps the page calm on small screens as well as large ones. Links look like [this inline link](#a-section-heading) and remain underlined so they are recognisable without colour.

> A quotation is set slightly larger, with a fine burgundy rule — one of the few places the accent colour appears in the reading view.

### A smaller heading

- Lists keep the same measure as the paragraphs.
- Items wrap with a hanging indent.
- Nothing here animates; the reading view stays still.

Footnote-style notes and references collect at the end of the page, together with image credits and, when a PDF is supplied, a download link. Reading time is calculated from the real word count of the text.
